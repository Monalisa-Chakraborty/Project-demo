# Canva User Manual for Beginners 

## 1. Introduction 

### What is Canva?

Canva is an online design platform 
that allows users to create presentation,
posters, social media post, documents,and other 
visual content.

### Who is this manual for?

This manual is designed for beginners 
who want to learn the basic features of 
Canva and create simple designs.

### What can you create with Canva?

With Canva, you can create:
- Presentations 
- Posters
- Social media
- Resume
- Flyers
- Documents
