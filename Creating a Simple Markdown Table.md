#  Creating a Simple Markdown Table 

## Introduction 

A Markdown Table is a type of table created using 
Markdown. It helps to organize information and
make it clear and simple. This guide will show 
how to create a simple Markdown Table.

## What is a Markdown Table?

A Markdown Table is a kind of table created 
using Markdown syntax. It helps to present information 
through rows and columns.

## Basic Table Structure 

To create a basic Markdown Table, a header, columns 
and rows are needed. A vertical bar (|) is used to 
separate columns, aand a hyphens are (-) are used to 
separate header from data.
